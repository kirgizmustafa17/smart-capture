# Product truth

## Product
SmartCapture PRO is a high-precision, privacy-first Chrome & Chromium screenshot extension equipped with DOM element sniffing, freehand organic clipping, full-page stitching, and an integrated Canvas Editor Studio.

## Platform
web
- **Target Browsers:** Google Chrome, Microsoft Edge, Brave, Opera, Arc, and Chromium-based browsers.

## Primary User & Use Scene
- **Audience:** Software developers, designers, QA engineers, product managers, and remote professionals.
- **Job to be Done:** Rapidly capture specific webpage elements, components, or screens, add annotations/callouts/censorship (pixelate/blur), and copy directly to the clipboard or download for bug reports, design reviews, and documentation.
- **Mode:** Operate (High-density, low-latency, scanability, precise keyboard shortcuts, keyboard-navigable).

## Core Workflows
1. **Element Capture:** Hover over DOM nodes; extension detects bounding boxes with selector and dimensions; 1-click capture.
2. **Rectangle / Freehand Capture:** Drag rectangular crop or draw organic lasso contours with sub-pixel canvas rendering.
3. **Full-Page Stitching:** Automated viewport scrolling and high-DPI canvas stitching.
4. **Editor Studio:** Annotation tools (Pen, Arrow, Rectangle, Circle, Highlighter, Text, Step badges, Crop), privacy filters (Mosaic, Blur), zoom/pan, and multi-format export (PNG, JPEG, WebP).

## Durable Constraints & Guarantees
- **Zero Remote Tracking:** 100% local processing in the browser sandbox. No external servers or telemetry.
- **Manifest V3:** Adheres to Chrome's latest extension manifest standards (Service Worker background, sandboxed storage).
- **Internationalization (i18n):** Native Chrome i18n support for Turkish (`tr`) and English (`en`).
